The Setup

Five steps to get Claude working for you

1

Fill out your profile

Go to getcarrieai.com and fill out one or more forms. Start with the Quick Profile — it takes 2 minutes and covers the essentials: name, airline, hotel, coffee, food.

If you travel frequently, fill out the full Travel Preferences form too. If you run a small business, add the Business Profile. Each form downloads a small JSON file when you're done — that's your profile.

Tip: Fill out all the forms that apply to you. The more Claude knows upfront, the less you ever have to explain.
2

Create a free Claude account

Go to claude.ai and sign up for free. You just need an email address.

The free plan works for basic use. If you want Claude to help with browser-based tasks (searching flights, looking up hotels), upgrade to Claude Pro for $20/month — but start free and see if you love it first.

Free plan is enough for: looking up your preferences, drafting emails, processing meeting notes, getting recommendations. Claude Pro adds hands-on browser automation.
3

Create a Claude Project

Once you're logged in to claude.ai:

On desktop: Look for "Projects" in the left sidebar → click "New Project" → give it a name like "My EA Assistant" or "Travel + Preferences."

On mobile (iPhone/Android): Open the Claude app → tap the menu icon → tap "Projects" → tap "New Project."

What is a Project? A Claude Project is a persistent workspace. Any files you upload and any instructions you add stay with every conversation in that project — Claude always has the context.
4

Upload your profile files

Inside your new project, look for a paperclip or "Add files" option. Upload the JSON file(s) you downloaded in Step 1.

You can upload multiple files — one for travel, one for food, one for business. Claude reads all of them.

Update anytime: If your preferences change, just fill out the form again on getcarrieai.com and re-upload the new file. Delete the old one from the project.
5

Add your project instructions

In your project settings, find "Project Instructions" or "System Prompt." This tells Claude how to behave in every conversation. Copy and paste the prompt below — customize the name and details to match yours:

You are my personal AI executive assistant. My preference profile is uploaded in this project — always reference it before making recommendations or bookings. My name is [YOUR NAME]. I am based in [YOUR CITY]. How to help me: - Look up my preferences before suggesting anything (flights, hotels, food, etc.) - Be concise — I'm busy. Bullet points where possible. - When I ask about bookings, walk me through my options based on my preferences. - When I ask "what's my [X]", look it up from my profile and tell me directly. - Draft emails and messages in a professional but warm tone. - If you're not sure about something, ask — don't guess. Always feel free to say "I don't see that in your profile — want to add it?"
That's it. Claude is now set up and ready. Start a new conversation inside the project and try one of the prompts from your Prompt Library.

"What are my travel preferences?"
"What's my coffee order?"

Claude should answer all three directly from your profile — no searching, no guessing. If it doesn't, double-check that your JSON file is uploaded in the project and the conversation is happening inside the project (not a regular chat).
